Cálculo de Cidades Dentro de um Raio com Python para o Power BI
Precisei desenhar um raio no Power BI e não havia opção nativa que atendesse — resolvi com Python orientado por IA. Solução para calcular cidades dentro de um raio (600 km) a partir de um ponto de referência.
  1. Definir coordenadas do ponto de referência
  2. Carregar dataset de cidades com lat/long
  3. Calcular distância com a função geodesic (Geopy)
  4. Filtrar cidades dentro do raio de 600 km
  5. Exportar e visualizar o raio no mapa do Power BI
