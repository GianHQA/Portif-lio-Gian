Cálculo de Cidades Dentro de um Raio com Python para o Power BI
Em um projeto, precisei desenhar um raio no Power BI e não encontrei uma opção nativa que atendesse — então resolvi com Python orientado por IA. Solução para calcular cidades dentro de um raio (neste exemplo, 600 km) a partir de um ponto de referência.
  1. Definir as coordenadas do ponto de referência (Manaus)
  2. Carregar um dataset de cidades com latitude e longitude
  3. Calcular a distância com a função geodesic da Geopy
  4. Filtrar as cidades dentro do raio de 600 km
  5. Exportar para Excel e visualizar no mapa do Power BI
